# Internship JavaScript Practice Repository

This repository contains a collection of JavaScript exercises and a small inventory dashboard project completed during an internship. The files are organized into practice assignments and a final console-based project.

## Repository Structure

- `Assignment/` - JavaScript exercises covering fundamentals such as variables, conditionals, loops, functions, and array methods.
  - `assignment1.js` - Variables, data types, and skill array output
  - `assignment2.js` - Bill tip calculator
  - `assignment3.js` - Grade calculator using `if`/`switch`
  - `assignment4.js` - Multiplication table, loop logic, and odd number generation
  - `assignment5.js` - Function scopes and arrow functions
  - `assignment6.js` - `forEach`, `filter`, and `map` examples
  - `index.html` - Basic HTML page used to reference assignment scripts
- `Project/` - Small JavaScript project for an inventory system.
  - `inventory-dashboard.js` - CLI application that adds products, classifies them, and calculates total inventory value.

## How to Run

From the project root, run any script with Node.js:

```bash
node Assignment/assignment1.js
node Assignment/assignment2.js
node Project/inventory-dashboard.js
```

## Skills Covered

- JavaScript fundamentals
- Control flow and branching
- Loops and iteration
- Functions and arrow functions
- Arrays and array methods (`map`, `filter`, `forEach`)
- Input handling and console-based interaction

## Project Goal

The inventory dashboard project demonstrates practical JavaScript usage for managing a simple product list, calculating totals, grouping items by category, and generating a quick report.
